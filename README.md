# amzphoto

A product-agnostic Codex skill for planning, generating, and auditing Amazon.in product listing images.

It builds a numbered gallery checklist, asks focused questions only when missing information affects accuracy, and tracks product facts, dimensions, and explicit visual constraints. It supports real-photo composites and explicitly requested AI-rendered drafts, with accuracy checks before upload.
